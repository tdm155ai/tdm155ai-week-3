# Tools

One line per thing. The glossary has the long entries.

## Studio lights

| Tool | What it's for |
| --- | --- |
| Bi-color LED panel, large | Key or fill. Bring it close for soft light. |
| Bi-color LED panel, small | Fill, or a hard key from far away. |
| Pocket RGB panel | Back light on the hair, or a color on the wall. |
| Diffuser | Makes the source bigger and the shadows softer. Costs brightness. |
| Foam core | Bounce fill, or a flag to block light. |
| Light stands | Height and angle. A key light sits above eye level. |
| Stool | Puts the subject at a fixed height so the setup can be repeated. |

## Studio cameras

| Tool | What it's for |
| --- | --- |
| Studio camera body | A big sensor. The lens mount is where everything interesting happens. |
| Zoom lens | One ring for framing, one for focus. |
| Prime lenses (a few focal lengths) | Fixed framing, wider apertures, character. |
| Tripod with fluid head | Locked-off frames and smooth pans. |
| OBS on the connected computer | The studio camera feeds it; the capture button saves a still to the wall. |
| Monitor | See the feed at a size that shows focus. |

## Camera obscura

| Tool | What it's for |
| --- | --- |
| 8×10 large-format camera | The real thing: lens, bellows, ground glass, dark cloth. Focus it first. |
| Three lenses on stands: 35 mm camera lens, 300 mm large-format, 909 mm spy lens | Three focal lengths, three image sizes, three distances to the sheet. |
| Ground glass | The 8×10's screen: catches the image so it can be seen. |
| Frosted acrylic sheets | The screen behind each of the three lenses. Same job as ground glass, doesn't break. |
| Dark cloth or dark corner | Makes the projected image visible. |
| Camera + monitor on its own feed | The recursion loop. |
| The prints | Frisius 1545, Kircher 1646, Zahn 1685. The station's ancestors. |

## Phone

| Tool | What it's for |
| --- | --- |
| Phone tripod / selfie stick | Eye level, a still frame, reach. Yours to keep. |
| DJI Osmo Mobile gimbal | Smooths rotation while you move. Not your footsteps. |
| Wireless mic set | Puts the mic six inches from the mouth while the camera stays back. |
| Headphones | The only way to hear what you recorded. |
| Blackmagic Camera app | Manual control: lock exposure, focus, white balance; see a histogram. |
| Your phone | A camera with a tiny sensor, a fixed lens, and a lot of software. |

## Control room

| Tool | What it's for |
| --- | --- |
| OBS capture button | Saves a still from the studio stations straight into the wall's folder. |
| Class image channel (Slack) | Where phone shots and videos go; they get pulled into the wall by hand today. |
| The live wall (`/live`) | Shows whatever is in `_media/`, newest first. |
